# Google Play Store Analytics Dashboard

An interactive Streamlit dashboard built using:

- Python
- Pandas
- Plotly
- Streamlit

Features:

✔ Category Analysis
✔ Rating Analysis
✔ Developer Insights
✔ KPI Cards
✔ Interactive Filters
✔ AI Generated Insights
✔ Beautiful Dashboard UI

Dataset:
Google Play Store Dataset (2.3M+ Apps)

Run:

streamlit run app.py
